# GOSOF80 – FPGA soundboard for Gottlieb System 80

FPGA replacement for the Gottlieb System 80 soundboards (MA-216, MA-309, MA-55, MA-490, plus
System 1 "Multisound") by bontango, [lisy.dev](https://lisy.dev/). A T65 (6502) runs the
original sound ROMs. An R6532 RIOT, a delta-sigma DAC and a DFPlayer for speech and background
music complete it. Speech comes either as MP3 or, from x.98 on, for MA-216 games with
**DIP 2 OFF**, from an emulation of the Votrax SC-01 after PinMAME
(`docs/Votrax_SC01_Implementierung.md`; not on Cyclone II).

## User manuals

**Read online:** <https://bontango.github.io/Gosof80/>

- [GOSOF HW 5.x user manual (English)](https://bontango.github.io/Gosof80/GOSOF_HW5x_user_manual.html)

## Downloads

The programming files (`.jic`, `.pof`) are not part of this repository. They are available at
<https://lisy.dev/swrep/soundboards>. They contain no game ROMs.

in `VARIANTEN.md`.

## Layout

```
top/GOSOF80.vhd        the top level of the System 80 boards
top/GOSOF80B*.vhd      the cores of System 80B
top/board_*.vhd        board shells
rtl/common/            all modules, T65, RIOT, GOSOF80.sdc
rtl/common/votrax/     SC-01 emulation (tables generated by sim/votrax/tools/gen_votrax_tables.py)
rtl/cyclone_II|IV|10/  megafunctions (SB_ROM, RAM) per FPGA family, same entity names
variants/<name>/       device.tcl, pins.tcl, variant.psd1, GOSOF80.qpf/.cof, GOSOF80.qsf (generated)
scripts/               gen_qsf.ps1, check.ps1, build.ps1, release.ps1, baseline.csv, version.psd1
docs/                  user manual and background (partly in German)
sim/votrax/            PinMAME reference, C model, GHDL testbenches: run_sim.ps1
```

## Building

```powershell
scripts\check.ps1 -Fit              # all variants: synthesis + fit + timing against baseline.csv
scripts\build.ps1 hw2x_cyclone_10   # full build of one variant, including the .jic
scripts\release.ps1 -DryRun         # shows which files a release would create (in bin\, not in git)
sim\votrax\run_sim.ps1              # Votrax: PinMAME vs. C model vs. VHDL (GHDL), ~25 min
```

The `.qsf` is generated: changes belong in `device.tcl`, `pins.tcl` or `scripts/files_*.tcl`,
followed by `scripts\gen_qsf.ps1`. Quartus writes to the `.qsf` when the project is opened in
the IDE; `check.ps1` and `build.ps1` therefore regenerate it before every run.

## History

Until 10.2026 each variant was a Quartus folder of its own, `GOSOF80_HW2x_*`, next to the
libraries `lib_common` and `lib_cyclone_*`. The other boards joined later as variants.
GOSOF80B: MA-766 see `docs/GOSOF80B_MA766.md`, MA-886 see `docs/MA-886_Evaluierung.md`.
